# 강남역 대중교통 통근시간 퀵필터 룩업 데이터 정밀 보정 계획

## 1. 개요 및 목적 (Background & Objectives)

### 현상 및 문제점
- **일산동구 하늘마을5단지 오노출 문제**:
  - `경기 고양시 일산동구 중산동 1800 하늘마을5단지` 매물이 "강남역 1시간 이내" 필터에 검색되었으나, 실제 대중교통 길찾기 시 약 1시간 40분이 소요됨.
  - 기존 룩업 맵에서 고양시 일산동구(`41285`)가 60분으로 설정되어 있어 발생한 오노출 현상.
- **수도권 전체 통근 교통망 반영 필요성**:
  - 사용자가 직접 작성한 수도권 대중교통 통근 조사 보고서(`docs/gangnam_traffic.md`) 기준에 맞추어 `commute_map.py`의 시군구별 소요시간(분) 데이터를 정밀하게 보정하고 확장함.

## 2. 정밀 보정 및 개편안

### A. 60분 이내 (1시간 이내 권역) 보정
- **서울 25개 구**: 전체 유지 (15~60분)
- **경기 핵심 1시간권**:
  - 성남시 분당구(25분), 수정구(30분), 중원구(30분)
  - 용인시 수지구(30분), 기흥구(40분)
  - 안양시 동안구(35분), 만안구(40분)
  - 과천시(25분) *[신규 추가]*
  - 구리시(40분) *[신규 추가]*
  - 하남시(35분)
  - 광명시(40분)
  - 의왕시(40분)
  - 군포시(45분)

### B. 60분권에서 90분권으로 이동 (오노출 방지)
- **고양시 일산동구 (`41285`)**: 60분 → **75분 (90분권 이동)** *(중산동 하늘마을 오노출 해결)*
- **고양시 덕양구 (`41281`)**: 55분 → **70분 (90분권 이동)**
- **부천시 (`41190`)**: 50분 → **70분 (90분권 이동)**
- **수원시 장안/팔달/권선구 (`41113`, `41115`, `41117`)**: 55~60분 → **75~80분 (90분권 이동)**
- **수원시 영통구 (`41111`)**: 50분 → **65분 (90분권 이동)**

### C. 90분 이내 (1시간 30분 이내 권역) 수도권 전체 확장 추가
- **경기 추가 권역**: 의정부시(41150), 안산시 상록구(41271)/단원구(41273), 오산시(41390), 시흥시(41395), 파주시(41480), 이천시(41500), 김포시(41570), 광주시(41610), 평택시(41220), 안성시(41550), 양주시(41630), 포천시(41650), 여주시(41670), 가평군(41820), 양평군(41830)
- **인천 추가 권역**: 부평구(28237), 계양구(28245), 남동구(28200), 연수구(28185), 서구(28260), 미추홀구(28177), 중구/동구(28110/28140)
