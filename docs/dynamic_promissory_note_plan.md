# 작업 계획서: 동적 차용증 작성인(이름, 가능 금액) 입력 행 추가/삭제 UI 및 합산 필터링

## 1. 개요
차용증 작성 활용 여부를 체크하면 바로 아래에 이름 및 가능 금액을 적는 동적 칸이 생성되고, `[+]` 및 `[-]` 버튼 제어를 통해 자유롭게 작성인을 추가/삭제하며, 입력된 금액들의 총합을 계산하여 정책대출 홈 화면 매물 필터링에 반영하도록 개발합니다.

## 2. 상세 개발 내용
1. **차용증 DTO 및 엔티티 확장**: `PromissoryNoteEntry(name, amount)` 정의 및 `ApplicantProfile.promissory_notes` 리스트 추가.
2. **동적 행 UI 및 토글 JS**:
   - `[+]` (왼쪽) + `이름` + `가능 금액` + `[-]` (오른쪽, 2번째 행부터) 구조 구현.
   - `[+]` 버튼 누르면 바로 아래에 새 행 삽입.
   - `[-]` 버튼 누르면 해당 행 삭제.
3. **폼 바인딩 및 백엔드 연동**: `promissory_note_names` 및 `promissory_note_amounts` 동적 파싱 후 `total_capital`에 합산 계산.
