# 수도권 인터랙티브 지도 위젯 및 계층형 줌인 지역 선택기 구현 계획서

지역 선택 필터 오른쪽 빈 공간에 서울/경기/인천 수도권 지도를 배치하고, 시/도 클릭 시 해당 지역 줌인(Zoom-in) 및 시/군/구 구역을 선택할 수 있는 인터랙티브 지도 위젯 구현 계획서입니다.

---

## 1. 주요 기능 요구사항

1. **수도권 인터랙티브 다크테마 미니맵 UI 배치**
   - 지역 선택 카드의 오른쪽 여백에 슬림하고 현대적인 SVG 기반 다크 테마 지도 위젯(`slate-900/90 border border-slate-700/80 rounded-xl p-3 shadow-inner`)을 탑재.

2. **2단계 드릴다운 줌(Zoom-in) & 계층 구조**
   - **Stage 1 (광역 뷰)**: 서울특별시, 경기도, 인천광역시 3개 광역 구역 표시.
     - '서울' 클릭 시 -> 드롭다운 `sido="서울특별시"` 설정 + 지도 UI가 **서울 자치구 뷰(Stage 2)로 확대(Zoom-in)** 전환!
     - '경기' 클릭 시 -> 드롭다운 `sido="경기도"` 설정 + 경기도 주요 시/군 구역 뷰로 Zoom-in!
     - '인천' 클릭 시 -> 드롭다운 `sido="인천광역시"` 설정 + 인천 자치구 구역 뷰로 Zoom-in!
   - **Stage 2 (시/군/구 자치구 뷰)**:
     - 확대된 뷰에서 '강남구', '서초구', '하남시', '송파구' 등 구역 노드를 클릭하면 -> 드롭다운 시/군/구 연동 선택 + 매물 검색 즉시 수행.
     - 상단에 **'← 수도권 전체'** 복귀 버튼을 배치하여 언제든 1단계 광역 뷰로 Zoom-out 지원.

3. **양방향 동기화 (Bi-directional Sync)**
   - 드롭다운이나 인기지역 칩을 통해 지역을 변경해도 지도의 뷰 상태와 하이라이트 노드가 자동으로 업데이트되도록 동기화.
