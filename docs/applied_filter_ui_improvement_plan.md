# 적용 필터 리스트 가독성 개선 및 UI/UX 디자인 보완 계획서 (applied_filter_ui_improvement_plan.md)

## 1. 목적
오른쪽 사이드바 필터 패널의 가로 폭이 좁아서 적용된 필터 칩의 문장이 2줄로 불필요하게 꺾이거나 가로 스크롤에 막혀 글자가 자려 보이는 현상을 해결하고, 필터 카테고리별 직관적인 심볼과 배지 색상을 도입하여 시각적 가독성을 대폭 향상함.

## 2. 세부 변경 내역
1. `_search_result_summary.html`:
   - 적용된 필터 칩 목록을 가로 스크롤(`whitespace-nowrap`) 대신 `flex-wrap` 멀티라인 칩으로 구성.
   - 단어 보존 줄바꿈(`break-keep`) 적용으로 글자 끊김 방지.
   - 카테고리별 심볼 아이콘 (📍, 🏷️, 💰, 📐, ⚡, 🏢, 🏦) 및 컬러 칩 적용.
2. `index.html`:
   - 우측 필터 영역의 강남역 통근권 퀵 필터 칩(`⚡ 강남역 1시간 이내 통근권`)의 텍스트와 패딩을 콤팩트하게 다듬어 2줄 꺾임 방지.
   - 검색 결과 요약 및 정렬 셀렉트 박스가 좁은 넓이에서 깔끔하게 정렬되도록 레이아웃 개선.
