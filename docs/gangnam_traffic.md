# 강남역 대중교통 1시간 30분권 — 수도권 전체 확장본

기존 **1시간 이내 지역을 포함해 1시간 30분 이내 지역까지** 수도권 전체를 다시 분류했습니다.

## 판정 기준

행정구역은 넓기 때문에 “해당 시·구 안의 모든 주소가 90분 이내”라는 의미는 아닙니다. 다음 기준으로 판단했습니다.

* **출발지:** 시·군·구청, 대표 생활권 또는 주요 철도역
* **도착지:** 강남역 승강장·출구권
* **포함:** 지하철, GTX, 광역버스, 시내버스, 환승·보행·평균 대기
* **제외:** 자가용, 택시, 예약형 KTX·SRT·ITX-청춘
* GTX-A 직결 운행 효과는 미리 반영하지 않고, 기존 개통 구간을 기준으로 보수적으로 판단

운정중앙–서울역 GTX-A는 약 22분, 수서–동탄은 약 21분이며, 별내선 개통으로 별내–잠실은 약 27분이 됐습니다. 이와 함께 신분당선·경강선·9호선 급행·각 지역 광역버스 노선을 반영했습니다. ([아시아경제][1])

| 표시             | 의미                  |
| -------------- | ------------------- |
| **◎ 기존 1시간권**  | 대표 생활권에서 대체로 60분 이내 |
| **○ 추가 90분권**  | 대표 생활권에서 대체로 60~90분 |
| **△ 일부만 90분권** | 특정 역세권·동네만 가능       |
| **× 90분권 제외**  | 대표 생활권에서 통상 90분 초과  |

# 1. 서울특별시

## 서울 25개 구 모두 1시간 30분 이내

서울은 기존과 마찬가지로 **25개 자치구 전체가 대표 생활권 기준 90분 이내**입니다.

종로구, 중구, 용산구, 성동구, 광진구, 동대문구, 중랑구, 성북구, 강북구, 도봉구, 노원구, 은평구, 서대문구, 마포구, 양천구, 강서구, 구로구, 금천구, 영등포구, 동작구, 관악구, 서초구, 강남구, 송파구, 강동구

다만 다음과 같은 서울 외곽 끝부분은 출발지와 버스 대기시간에 따라 80~90분 가까이 걸릴 수 있습니다.

* 도봉구 도봉산·도봉동 북부
* 노원구 상계동 북단
* 은평구 진관동·북한산 방향
* 강서구 방화동·김포공항 서쪽
* 강북구 우이동 북단

## 실거주·부동산 검색용으로 적용할 때

**강남역 1시간 30분 통근권**을 실제 매물 필터로 사용할 경우에는 다음처럼 적용하는 것이 안전합니다.

* 지도 앱 표시 시간이 **80분 이하:** 비교적 안정적인 90분 통근권
* **81~90분:** 철도 중심이며 환승 1회 이하일 때만 고려
* **광역버스 중심 81~90분:** 출근시간에는 90분을 넘길 가능성이 높음
* 집에서 역까지 마을버스를 타야 한다면 **최소 15분을 추가**
* GTX는 열차 이동시간보다 역사 진입·환승·배차시간이 길기 때문에 **표시 열차시간만 보면 안 됨**

따라서 매일 출퇴근할 집을 찾는 목적이라면 **검색 결과 75~80분 이내**, 역 도보 10분 이내를 실질적인 상한선으로 잡는 것이 좋습니다.
