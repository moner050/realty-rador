# 경기도 글자 위치 조정 & 브라우저 리사이징 시 100% 비율 동기화 반응형 맵 캘리브레이션 계획서

경기도 칩 위치를 살짝 왼쪽 밑(`top: 62.5%; left: 54.5%;`)으로 미세조정하고, 브라우저 창 크기를 줄여도 지도 원본 글자와 오버레이 칩 위치가 단 1픽셀도 어긋나지 않도록 이미지 래퍼 종횡비(Aspect-Ratio) 반응형 구조를 구축하는 계획서입니다.

---

## 1. 개선 개요

1. **경기도 글자 위치 미세조정**
   - 기존: `top: 61%; left: 56.5%;`
   - **수정**: `top: 62.5%; left: 54.5%;` (살짝 왼쪽 밑으로 이동)

2. **브라우저 창 리사이징 시 100% 비율 동기화 (Responsive Aspect-Ratio Sync)**
   - 지도 이미지 래퍼를 `inline-block relative aspect-auto` 혹은 이미지 종횡비 컨테이너로 감싸 브라우저 창을 줄이더라도 오버레이 칩의 `%` 기준 좌표와 이미지의 실제 경계가 항상 100% 동기화되도록 반응형 레이아웃 강화.
