# 지도 초기 범위 및 조회 지연 설계

## 목적

처음 지도는 서울·경기·인천이 보이는 수도권 범위로 시작하되, 초기 로딩에서는 지도·카드 API를 호출하지 않는다. 사용자가 지도를 조작한 뒤 멈추면 1.5초 후에만 현재 뷰포트의 조건 충족 매물을 갱신한다.

## 동작

- 지도 생성 시 중심 좌표는 수도권 중심으로, 줌은 서울·경기·인천을 함께 볼 수 있는 8로 설정한다.
- 초기 화면은 안내 상태만 보여 주며 지도 요약·마커·카드 목록을 자동 조회하지 않는다.
- 사용자의 드래그·확대·축소 뒤 `idle`이 발생하면 1.5초 디바운스를 시작한다.
- 새 조작이 들어오면 기존 타이머와 진행 중인 지도·카드 요청을 취소한다.
- 디바운스가 끝나면 기존 규칙대로 지도 데이터를 먼저 조회한다. 줌 11 이상이면 카드 목록도 조회하며, 기존 목록은 새 응답이 올 때까지 유지한다.
- 목록 카드 클릭, 클러스터 확대 등 프로그램상 지도 이동은 기존 최신 뷰포트 보호 규칙을 유지하며 1.5초 뒤 갱신한다.

## 범위와 호환성

- 기존 축소 지도 요약(`zoom < 11`), 확대 마커/카드, 모달, 필터와 URL 비영속성은 바꾸지 않는다.
- 서버 API, 스키마, 데이터 수집·지오코딩은 변경하지 않는다.

## 검증

- 브라우저 컨트롤러 테스트로 초기 중심·줌, 초기 조회 없음, 1.5초 이전 조회 없음, 마지막 조작 뷰포트만 조회를 검증한다.
- 기존 지도·목록 상호작용 테스트와 전체 Python 테스트를 실행한다.
