# 통합 검색 패널 및 지도 수명주기 설계

## 목표

기본 필터와 검색 결과 요약을 한 개의 읽기 쉬운 제어 패널로 배치하고, 필터 적용 중에도 현재 지도 인스턴스와 사용자가 선택한 위치·줌을 유지한다.

## 확인한 원인

현재 검색 폼은 HTMX로 `#search-results`를 `outerHTML` 교체한다. 이 영역에는 `data-listing-map-root`와 NAVER 지도 컨테이너가 함께 포함되어 있다. 교체 뒤 `listing-map.js`의 `htmx:afterSwap` 처리기는 교체 전 대상에서 지도를 다시 찾으므로, 새 `data-listings-map` 컨테이너를 초기화하지 못한다. 재현 시 최초 지도 컨테이너에는 NAVER 지도 자식 요소 4개가 있었지만, 필터 적용 뒤 새 컨테이너에는 자식 요소가 0개였다.

## 화면 구조

검색 페이지는 아래 세 영역으로 구분한다.

1. `data-search-control-panel`은 하나의 카드 안에 기본 필터 행, 상세 필터 진입점, 검색 실행, 검색 결과 요약, 정렬, 적용 조건 칩을 넣는다. 결과 요약은 기본 필터 행과 구분선으로만 나누며 독립 카드·그림자·중복된 “필터 변경” 링크를 제거한다.
2. `data-listing-map-root`는 검색 결과 교체 대상 밖에 둔다. NAVER 지도 DOM은 HTMX 검색 중에 삭제하거나 재생성하지 않는다.
3. `#listing-collection`은 지도 아래의 카드 영역으로 유지한다. 검색·정렬 결과 및 페이지 이동은 이 컬렉션만 교체한다.

모바일에서는 기본 필터 행이 자연스럽게 여러 줄로 흐르고, 결과 요약의 정렬·상세 필터 버튼은 결과 제목과 같은 행에서 줄바꿈을 허용한다. 상세 필터는 기존 오른쪽 서랍과 현재의 색상 토큰을 계속 사용한다.

## 검색 갱신 계약

검색 폼의 HTMX 대상은 `#listing-collection`이다. 검색 응답은 다음 세 조각으로 구성한다.

- 일반 교체 대상: 최신 `#listing-collection`.
- out-of-band 교체 대상: `#search-result-summary`, 결과 수·정렬·적용 조건 칩을 갱신한다.
- out-of-band 교체 대상: `#map-search-config`, 최신 필터가 포함된 지도 데이터·지도 카드·단지 상세 URL을 전달한다.

`#map-search-config`는 숨김 요소이며 지도 DOM을 포함하지 않는다. 서버가 현재 필터로 생성한 URL을 그대로 제공하므로 저장 필터, URL, 지역 코드, 상세 조건의 기존 파싱과 서버 검색 의미는 바꾸지 않는다.

## 지도 갱신 동작

`listing-map.js`는 `#map-search-config`가 교체된 뒤 현재 지도 루트의 URL 데이터셋만 갱신한다. 이미 생성된 NAVER 지도 인스턴스, 중심 좌표, 줌, 이벤트 리스너는 유지한다.

필터 적용으로 새 지도 쿼리가 도착하면 진행 중인 지도·카드 요청을 취소하고, 현재 뷰포트 기준으로 지도 데이터와 카드 데이터를 즉시 한 번 갱신한다. 이는 사용자가 지도 이동·확대를 끝냈을 때 적용되는 기존 1.5초 지연과 분리한다. 이후 지도 이동이나 확대에는 현재의 1.5초 지연, 최신 요청 토큰, `AbortController` 규칙을 계속 사용한다.

지도 설정 조각이 없거나 뷰포트를 읽을 수 없으면 현재 지도를 지우지 않는다. 상태 문구만 실패를 알리고 기존 마커·카드 목록을 남긴다.

## 테스트와 검증

- 서버 렌더링 테스트는 통합 제어 패널이 기본 필터와 `#search-result-summary`를 포함하며, 지도 루트가 검색 컬렉션 교체 대상 밖에 있음을 확인한다.
- HTMX 검색 응답 테스트는 컬렉션 본문과 두 out-of-band 조각을 반환하고, 지도 URL에 현재 필터가 보존됨을 확인한다.
- 지도 컨트롤러 테스트는 지도 설정 갱신이 NAVER 지도 인스턴스를 삭제·재생성하지 않고 현재 뷰포트로 새 요청을 시작함을 확인한다. 지도 이동 후 1.5초 지연 규칙도 유지한다.
- 브라우저에서는 확대된 지도에서 필터를 바꾼 뒤 타일이 계속 보이고, 같은 중심·줌에서 새 마커와 카드가 갱신되는지 확인한다. 데스크톱과 모바일에서 통합 패널의 줄바꿈·대비를 확인한다.

## 비목표

- 지도 스키마, 마이그레이션, 지오코딩, 외부 데이터 수집은 변경하지 않는다.
- 저장 필터 형식, URL 파라미터, 검색 SQL, 지도 확대 단계별 집계 규칙은 변경하지 않는다.
- 사용자 문서의 기존 변경은 이 작업에 포함하지 않는다.
