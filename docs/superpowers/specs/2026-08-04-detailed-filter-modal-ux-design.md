# 상세 검색 조건 모달 UX/UI 개선 설계

## 목표

상세 검색 모달에서 중복되거나 경쟁하는 조작 방식을 정리해, 자주 쓰는 예산·면적·주거 조건을 빠르게 확인하고 세부 조건은 필요할 때만 펼쳐 사용할 수 있게 한다.

## 범위와 불변 조건

- 모든 기존 form `name`, URL 쿼리 값, 저장된 검색 조건, 서버 필터 의미는 유지한다.
- 가격·면적·월세·주거·대출·통근·옵션 필터를 삭제하거나 합쳐 의미를 바꾸지 않는다.
- 직접 숫자 입력은 정확한 값 설정의 기준 조작이며, 슬라이더는 보조 조작으로 유지한다.
- 라이트/다크 모드 모두에서 보조 텍스트, 경계, 비활성 상태, 초기화 동작이 읽혀야 한다.
- 모달은 키보드와 작은 화면에서 사용할 수 있어야 하며, 긴 모달의 적용·초기화 동작은 항상 분명해야 한다.

## 정보 구조

### 1. 예산·면적

주거 탭의 가격·면적을 하나의 첫 번째 카드로 묶는다.

- 거래 유형에 맞는 가격/보증금 범위를 첫 줄에 둔다.
- 전용면적 범위를 같은 카드의 두 번째 줄에 둔다.
- 각 범위는 `최소 · 최대` 직접 입력과 단위만 항상 노출한다.
- 슬라이더, 평수 환산, 최소/최대 안내, 개별 초기화는 입력 아래의 보조 영역으로 정리한다.
- 월세 상한은 월세 거래일 때만 예산·면적 카드의 세 번째 줄로 노출한다. 기존 거래 유형 전환 로직을 재사용한다.

이 구조는 같은 값이 입력란, 슬라이더 툴팁, 별도 카드에 반복되는 인상을 줄이되, 기존 범위 입력과 슬라이더의 정밀도는 유지한다.

### 2. 주거 조건의 점진적 공개

주거 조건은 두 계층으로 나눈다.

- **기본 주거 조건:** 준공연도, 세대수, 방 수, 욕실 수.
- **세부 주거 조건:** 주차 대수, 관리비 상한, 역 도보 상한, 최근 등록.

기본 조건은 2열 카드 그리드로 바로 보이며, 세부 조건은 접힌 `details` 영역에서 연다. 모든 값은 기존 단일 슬라이더 컴포넌트와 hidden input을 사용하므로 검색 동작은 변하지 않는다.

### 3. 대출 프리셋의 중복 해소

프리셋 탭은 목적을 두 그룹으로 분리한다.

- **추천 조합:** 대출 조건과 선호 주거 환경을 함께 적용하는 조합 버튼.
- **대출 조건만:** 대출 한도·면적 중심의 개별 프리셋 버튼.

각 그룹에는 한 줄의 설명을 두고, 버튼은 적용되는 핵심 값만 짧게 표시한다. 기존 `data-quick-preset`과 가격 범위 속성은 그대로 둔다.

### 4. 옵션의 목적별 그룹화

옵션 탭은 동일한 체크박스 이름과 값을 유지하면서 아래 순서로 구획한다.

- **거래·매물 형태:** 직거래, 단기임대 제외, 1층 제외, 단지별 묶기.
- **주거 편의:** 주차 가능.
- **자금 조건:** HUG 안전 임대인, 대출 가능 매물, 구매 가능 매물.

자금 조건에는 사용자 자격 정보가 필요한 필터일 수 있음을 짧게 안내한다. 이 그룹화는 `대출 가능`과 `구매 가능`의 서로 다른 의미를 보존한다.

### 5. 모달 조작과 상태

- 제목 아래 탭은 각 탭의 목적을 짧은 이름으로 표시한다.
- 각 탭의 상단에는 현재 탭의 역할을 설명하는 문구를 하나만 둔다.
- 하단 고정 작업 영역에는 현재 적용 필터의 개수/요약과 `이 탭 초기화`, `적용 및 닫기`를 둔다.
- `이 탭 초기화`는 해당 탭이 소유한 입력만 초기화한다. 전체 초기화는 기존 페이지 수준 동작을 유지한다.
- 적용 버튼은 기존 form 제출과 모달 닫기를 한 번만 실행한다.

## 구현 경계

주 변경점은 `src/realty_radar/web/templates/listings/index.html`의 마크업, 기존 슬라이더 매크로의 배치 옵션, 모달 제어 JavaScript, 그리고 필요한 소규모 스타일이다. Python 필터 파싱·DB 쿼리·저장 데이터는 변경하지 않는다.

## 검증

- 렌더링 테스트는 기존 필터 이름, 현재 값, 선택된 체크박스, 거래 유형별 월세 노출을 확인한다.
- 브라우저 검증은 라이트/다크 모드, 기본/세부 주거 조건 접기, 탭별 초기화, 적용 후 URL 및 결과 갱신을 확인한다.
- 전체 Python 회귀와 지도 컨트롤 회귀를 실행한다.

## 자체 검토

- 범위: 상세 검색 모달 내부의 정보 구조와 시각적 조작만 다룬다.
- 일관성: 직접 입력과 슬라이더, 기존 query parameter 및 체크박스 이름을 모두 보존한다.
- 모호성: 월세는 기존 거래 유형 표시 규칙을 그대로 재사용하고, 탭 초기화는 해당 탭의 입력만 대상으로 한다.
