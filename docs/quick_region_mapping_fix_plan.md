# 인기지역 퀵 선택 필터 매핑 오류 수정 및 DB 데이터 동기화 계획서

인기지역 퀵선택 버튼 클릭 시 매물이 표시되지 않는 문제에 대한 원인 분석 및 수정 계획입니다.

## 1. 원인 분석

1. **DB 실제 수집 데이터와 태그 칩 미매핑**
   - 현재 DB(총 157,038건)에 수집된 실제 데이터에는 `강남구`(15,481건), `서초구`(13,178건), `마포구`(6,497건), `남양주시`(15,516건), `하남시`(3,962건), `강동구`(4,835건), `동작구`(5,923건), `영등포구`(218건) 등이 존재하는 반면,
   - 기존 태그 중 `분당구`, `과천시`, `송파구` 등은 DB에 수집된 매물이 없거나, `여의도`의 경우 행정구역 구(district)가 아니라 '동' 및 '영등포구'로 등록되어 매칭되지 않았습니다.

2. **프론트엔드 `setQuickRegion` JavaScript 매핑 함수 한계**
   - `index.html`의 `setQuickRegion(region)` 함수가 `koreaRegionData['서울특별시']`만 하드코딩 검사하여, 서울 외 지역 및 복합 지역명 선택 시 계단식 주소 선택기(`select-sido`, `select-sigun`)와 바인딩되지 못하고 필터 조건이 비정상 파싱되는 문제가 있었습니다.

---

## 2. 주요 수정 계획

### [Frontend] `src/realty_radar/web/templates/listings/index.html`
- **인기지역 태그 칩 목록 업데이트**:
  - 실제 DB 매물이 풍부하게 존재하는 대표 인기지역으로 태그 바 수정: `강남구`, `서초구`, `마포구`, `강동구`, `동작구`, `영등포구`, `하남시`, `남양주시`
- **`setQuickRegion` 매핑 핸들러 보완**:
  - 선택한 지역명에 따라 `서울특별시`, `경기도`, `인천광역시` 등 모든 지역 구조를 재귀적으로 검색하여 `select-sido` 및 `select-sigun`을 자동으로 올바르게 선택하고 hidden 파라미터를 동기화하도록 유연화.
