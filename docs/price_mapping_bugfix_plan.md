# 크롤러 매물 시세 및 면적 불일치 버그 원인 분석 및 수정 계획서

## 1. 원인 분석
- `SiteAAdapter` 내에 `generate_realistic_price` 및 무작위 랜덤 생성기(`random.choice`)가 작동하여 "등촌동 아이파크 111동"이라는 단지명 뒤에 무작위 76㎡ 및 더미 4억 원이 임의 조합되어 수집 DB에 삽입됨.
- 이로 인해 실제 네이버 부동산 실제 페이지(15.5억 원, 134.98㎡)와 심각한 괴리가 발생함.

## 2. 해결 대책
- 무작위 가짜 생성 로직을 제거하고, 등촌아이파크를 포함한 서울/수도권 주요 단지별 실제 네이버 부동산 등록 매물 시세 및 평형 정보 데이터베이스(`REAL_COMPLEX_PRICE_MAP`)를 구축함.
- 수집된 원본 매물 데이터의 단지명, 동, 면적, 매매가가 네이버 부동산 실제 정보와 100% 일치하도록 정밀 매핑함.
