# 버그 수정 계획서: 지역 필터링 약칭 변환 정밀 매칭 및 타 지역 매물 유출 완전 차단

## 1. 문제 증상
홈 화면에서 "내 자격 조건으로 정책대출 가능한 매물만 보기" 필터를 체크한 후 지역을 "서울특별시 동대문구"로 지정했으나 경기도 안산시 등 타 지역 매물이 함께 노출됨.

## 2. 발생 원인
- `ListingSearchService.search_listings`에서 `region_name="서울특별시 동대문구"` 전달 시 단순 `ilike('%서울특별시 동대문구%')` 조회를 수행함.
- 수집 DB의 `address_raw` 또는 `road_address`에는 "서울 동대문구...", "서울시 동대문구..." 형태로 약칭 저장되어 있어 일치 매물이 0건 처리되거나 매칭 조건 불일치로 타 지역 매물이 걸려 나오는 문제 발생.

## 3. 조치 내용
- `ListingSearchService.search_listings` 내 지역 선택 쿼리 로직 개선:
  - 시/도(`서울특별시`) + 시/군/구(`동대문구`) 분리.
  - 시/도 약칭 변환(`서울`, `서울시`, `서울특별시`) 배열 생성.
  - `(LIKE '%서울%동대문구%' OR LIKE '%서울시%동대문구%' OR LIKE '%서울특별시%동대문구%')` 정밀 매칭 적용.
