# 경기도 지도 겹침 0% 가독성 재배치 & 우측 성남시 하위 구 선택 UI 개편 계획서

경기도 지도 오버레이 칩의 겹침 현상을 100% 제거하고, 우측 세부 구역 선택 영역에서 `성남시 분당구`, `성남시 수정구` 같은 지저분한 시/구 합성 칩을 제거하고 시 단위 클릭 시 하위 구 종류가 깔끔하게 펼쳐지거나 조회되는 UI 개편 계획서입니다.

---

## 1. 주요 개편 내용

1. **경기도 지도 겹침 0% 깔끔한 오버레이 캘리브레이션**
   - 구가 복수 개 존재하는 성남시, 수원시, 고양시, 용인시, 안양시, 안산시는 지도 오버레이에 **'성남시'**, **'수원시'**, **'고양시'**, **'용인시'**, **'안양시'**, **'안산시'** 단일 칩으로 깔끔하게 포개어 겹침 현상을 100% 해소.
   - 28개 전체 경기도 시/군 오버레이 좌표를 캡처 3번 이미지의 실제 위치로 100% 밀착 포개어 가독성 100% 극대화.

2. **우측 세부 구역 선택 칩 리스트 개편**
   - `성남시 분당구`, `성남시 수정구` 등 글자가 잘리던 복합 칩 전면 제거.
   - **'성남시'**, **'수원시'**, **'고양시'**, **'용인시'**, **'안양시'**, **'안산시'** 등 대표 시 칩으로 단순화.
   - 대표 시(예: 성남시)를 클릭하면 우측 칩 영역에 하위 자치구(**[전체, 분당구, 수정구, 중원구]**) 서브구역 선택 칩들이 즉시 전환되어 표시되도록 하위 구 조작 UI 구현.
